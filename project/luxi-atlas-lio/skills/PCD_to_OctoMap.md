# Skill: PCD to OctoMap Converter

## Goal

Convert a PCD point cloud map generated by Luxi-Atlas-LIO, FAST-LIO2, FAST-LIVO2, LIO-SAM, or Point-LIO into a 3D OctoMap occupancy map.

---

## Input

```text
map.pcd
```

Supported point types:

```text
XYZ
XYZI
XYZRGB
```

---

## Output

```text
map.bt
```

Optional:

```text
map.ot
```

---

## Workflow

```text
PCD
 ↓
PointCloud
 ↓
Voxel Filtering
 ↓
OctoMap
 ↓
map.bt
```

---

## Command Line

```bash
pcd2octomap \
    --input map.pcd \
    --resolution 0.05 \
    --output map.bt
```

---

## Parameters

```yaml
input:
  input pcd file

output:
  output octomap file

resolution:
  voxel size

min_z:
  minimum accepted height

max_z:
  maximum accepted height

hit_prob:
  occupancy update probability

miss_prob:
  free-space update probability
```

---

## Recommended Settings

Indoor:

```yaml
resolution: 0.05
```

Outdoor:

```yaml
resolution: 0.10
```

---

## Output Files

```text
map.bt
```

The generated OctoMap contains:

* Occupied Voxels
* Free Voxels
* Unknown Voxels

and can be used for:

* Nav2
* Habitat-Sim
* VLM Mapping
* UAV Planning
* 3D Navigation
